## 1. Automation Execution Guide for AI Tools
To automate any test case below using an AI code generator (e.g. Playwright / TypeScript):
1. **Locate Target Screen:** Read the `Screen / Location` and navigate using the application sidebar routing.
2. **Setup Preconditions:** Ensure an active authenticated session using `loginAs(role)` helper.
3. **Execute Steps:** Translate `Test Steps` into explicit Playwright locator commands:
   - Click actions: `await page.locator('...').click();`
   - Input fills: `await page.locator('...').fill('...');`
   - Dropdown selections: `await page.locator('...').selectOption('...');`
4. **Assert Expected Results:** Translate `Expected Result` and `AI Direct Automation Instruction` into assertions:
   - Visibility: `await expect(page.locator('...')).toBeVisible();`
   - Read-only: `await expect(page.locator('...')).toHaveAttribute('readonly', '');`
   - Count / Removal: `await expect(page.locator('...')).toHaveCount(0);`
   - Limits: `await expect(page.locator('...')).toHaveAttribute('maxlength', '250');`
